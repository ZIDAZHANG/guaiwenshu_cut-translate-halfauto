## 增加了什么

- 原文片段主记录、来源字符范围、稳定片段身份、原始画面与语音证据、对应与复核报告。
- 多种边界模式、可追溯的无声文字与不确定时间处理。
- 原 Whisper 坐标冲突自动恢复，完整保留 VAD 与无 VAD 两次实际输出。
- 翻译原始 HTTP 审计、流式进度、完整子请求即时保存及恢复。
- 字典认可项以外的日文假名残留复核，保留完整译文，传递到最终 review.csv 和质量状态；不设置残留字数上限、不拒绝整份输出。
- 可配置的采样参数，GUI 保存时保留未单独显示的翻译配置字段。
- 固定版本、隔离环境的辅助工具调查：Qwen3 ForcedAligner、RapidOCR/PP-OCRv6；尚未通过的结果不默认接入。
- 原素材定位清单、原草稿副本、35 秒测试切片、长片诊断、版本快照与交接说明。

## 减少、移除了什么

本轮已移除或不再让其截断内容的规则：最多拼接 3 条/max_join、按字幕条数差异 5% 拒绝、只显示前 200 条任务、翻译 max_tokens=384、模型上下文夹在 4096–65536、GUI 批量上限 30、强制短句/一句话式翻译要求、Sakura 240 秒加载和生成截止、GUI 错误文字及文件名截断、Magia 最大分辨率 2000、外部文件等待 3600 秒、诊断日志 2 MB 截取。队列默认无活动超时改为 0，外部文件等待默认 0（等待直到就绪）。第 8 轮移除了相同时间/相同文本事件的拒绝规则。

没有新增单句长度、单句时长、台词条数、固定阅读速度、必须语音停顿才能切句、固定句间空隙或固定生成字数上限。没有把官方“建议 7–10 句”变成产品上限。任意长度输入仍受实际模型内存与上下文能力约束，工具报错时保留实际失败，不能裁掉台词来假装成功。

## 本轮加入且仍保留的全部约束

以下是本轮加入或强化的输出验证、对应规则与运行要求。它们也属于用户要求披露的限制，不能用“无限制”概括。

| 约束 | 影响、依据和失败行为 |
| --- | --- |
| 主记录必须覆盖每个原语音字符一次，范围合法、原文一致，来源身份唯一 | 防止掉句、串句和重复分配；失败不发布派生字幕。不同来源的同文同时间重复允许，ID 按出现顺序区分 |
| 派生字幕必须有正向时间，且位于实际媒体范围 | 防止字幕出片、反向或无时长；不偷偷裁剪到视频结尾。原始父句越界仍完整保留并报告，若影响最终段则失败 |
| 原字/词时间必须与原 SRT、JSON、UTF-8 token 完整对应 | 不允许听写文件与另一份时间文件拼接；损坏、少字、不同来源或不完整 UTF-8 拒绝作为可靠时间 |
| native 词坐标冲突会使该次词时间整体不可用 | VAD 可能使用压缩音频坐标；不加容差、猜偏移或插值。已加入完整无 VAD 自动重跑；重跑未合格则仍用原父句候选并标记，可能增加一次识别耗时 |
| 正向时间重叠及父句/画面文字锚点用于自动对应 | 不把不同时间的同文机械配对；不支持仅凭替换字符锚定到另一父句。比较允许假名等价，原文字完整保留；未确定项留在复核记录 |
| 相同画面连续事件仅在整段文字对应编辑代价严格改善时合并 | 平手不吞真实重复；保留全部原画面身份。没有最大拼接数 |
| 缺观测词边界时不制造按字数等分时间 | speech 模式使用连接父句的原时钟并标记 WORD_TIMING_MISSING/CHECK；可能有重叠待复核。mixed/screen 画面边界不能代替音频证据 |
| 中文仅接回完全匹配的 cue_id/index/text/start/end 及当前输入签名 | 源文、时间、源码、配置、模型、提示词或相关字典改变后旧 checkpoint 失效；避免把旧译文接到新轴上 |
| 默认翻译正文不得含参考文字、编号或时间码 | 系统追加传输说明；用户自定义风格和字典原样保留。这是模型请求规则，不删除用户字幕；稳定身份由程序保管 |
| 普通单行批次只有完整非空行数一致才按输入顺序对应 | 行数对应本身不证明中文语义正确；不一致保存原响应后逐条翻译，每次仍保留整批参考。不猜缺行位置 |
| 多行台词作为一个完整翻译单元 | 内部换行与全部文本保留；本轮因此可能增加 HTTP 次数，未设条数或长度上限 |
| HTTP/SSE 必须完整、可解析，有正常结束标志和 finish_reason；length 截断响应不作为完成译文 | 不接受连接断开的半句或流式未结束内容；已收到的字节留档。无 max_tokens 或生成超时；模型若继续生成会一直等待，用户可取消 |
| 子请求完成映射后保存，未完成生成不算完成 | 完整响应才能接回稳定身份；过程文本留原始审计，不把半句写成 final。恢复只复用已保存的完整对应 |
| 原 Whisper 非零退出、空输出、无效输出不覆盖已有良好产物 | 失败部分单独保留；不能把 partial SRT 当作成功。自动恢复也必须同一输入且验证合格 |
| 独立 Qwen 对齐只接受固定模型/SDK、实际音频/原文与原始预测可核验的证据 | SDK 修补时间、反向或无法核验的预测不被称为实测词边界；默认关闭。当前完整长片只有 6/2010 单元合格，不能作为已可用功能 |
| 占位画面文字 Subtitle_Dialog_... 不当作真实字幕翻译 | 原 ASS 保留；此工具占位标记不能复制进多段中文，不是按长度过滤台词 |
| 字典认可之外的假名残留标记 CHECK | 不自动删除、拒绝或改写输出；可能将未配置字典的合法日文名字也标为待复核。字典认可的完整目标文本允许保留；此检查不能发现所有中文语义错误 |
| 原始审计与固定版辅助环境落盘 | 会增加磁盘占用；本轮没有日志/素材截取上限，没有自动删除旧成果 |

## 原有工具条件与验收边界

这些不是本轮新加的字幕内容上限，但会影响使用：模型必须存在且匹配引擎（Whisper ggml 与 Faster Whisper CTranslate2 不通用）；词时间需要对应 DTW 模型；批量大小须为正；模型窗口、内存和硬件资源实际有限。当前保留用户 batch_size=10、context_size=16384、gpu_layers=100，没有加入自行夹取的上限。正文请求采样从旧 0.15/0.9 改为官方建议的 0.3/0.8；translation.temperature/top_p 可覆盖，不自行夹取，改变后旧 checkpoint 不复用。GUI 保存配置会保留这两个未单独展示的字段。实际一轮语音输出完成，但另一轮混合输出仍循环；默认提示词随后统一正文格式后混合输出完成，这些结果不证明参数能保证稳定或语义准确。HTTP 失败默认 retries=2、健康检查 3/5 秒、自有进程收尾等待等属于原运行参数；生成与加载无固定截止。

既有进程保护要求仍在：自动启动限于本机服务，使用已存在服务前检查模型，只关闭本轮拥有的进程。原字典的条件/情景项因 direct SRT 缺少 GalTransl 完整句元数据而跳过并警告；不是悄悄抹掉字典，原文件留在原安装中。默认词表、用户字典和自定义提示词均需分别核实。

RapidOCR 第 7 轮在实际帧上识别对了アルダン和逃さん，也有背景文字、假名及行顺序错误。该诊断使用 CPU、PP-OCRv6 medium、upright 图不做方向分类、全幅图不走自动预缩放；检测边长 1080 对应该帧实际高度，工具默认 score=0.5/max_candidates=1000 等全部记录在报告。这些参数尚未成为产品默认限制。

当前 GUI 可启动，但截图工具持续超时；剪映 11.4 实际导入、重导入及导出还未完成验证。模型仍可能听错名字、误译人称和语气。已合法生成字幕或 tests passed 不能证明“自动化且准确无误”。用户在 2026-10-12 明确改为软件可用即可停止；本轮完成生成/恢复/启动检查后停止，以上准确性和 UI 缺口仍如实保留。

## 第 8 轮最新补充（优先于前面的阶段性记录）

Sakura 完整模型文件与官方 SHA 一致；完全 CPU 运算仍复现错误，未把 GPU 调成 0 作为生产限制。频率惩罚 0.1 没有解决实际循环，未作为生产默认。Qwen3-8B 已下载核验完成，实际兼容调用成功，但不同设置和双 OCR 上下文仍错义，未替换原软件、原模型或加入自动后备。

翻译传输追加 native 模型前缀，术语表按其训练格式放在 user。所有自定义语义风格保留。完整父句已在本轮待译正文中出现时，不再重复作为 system 内的一份日文；原父句、每次真实台词及原始请求审计均完整保留。这个条件只减少冗余参考副本，不删除待译重复台词。正文未包含完整父句时仍保留完整参考，没有参考长度上限。

曾尝试将画面原 OCR 直接加入翻译参考，真实模型出现循环，所以该默认实现已回退。画面 OCR、RapidOCR 全部行/框/分数仍在诊断证据中；没有把辅助 OCR 输出偷偷改作原听写。新视觉辅助模型、CPU 参数、频率参数和 XML 参考格式均是隔离诊断，不是交付版新条件。

native GPT seed 新增 3 个可编辑词条：ラモーヌ -> ラモーヌ [待确认]、ラモさん -> ラモさん [待确认]、アルダン -> 阿尔丹。前两项是尚未确认中文名的保留策略，后者来自已有用户姓名译法的简称。原 seed 已备份，只更新与该 seed 相同的候选；没有改用户 JSON 字典、没有添加“ある男”这种歧义词的全局替换。这些词条可能仍被模型忽略，当前真实切片 3 处未遵循，已明确进入复核，不能称为专名已经修好。

新增的两项复核约束：匹配到的 native GPT 目标词缺失，标记 TRANSLATION_TERM_MISSING/CHECK；模型输出 [待确认]，标记 TRANSLATION_UNCERTAIN/CHECK。两者都不拒绝、删除或硬改译文。前者是严格字面目标检查，同义写法/目标中的标记未遵守也会报警；后者仅识别该明确标记，不能发现所有隐性不确定性。字典语言豁免仍按完整目标字符串匹配。质量汇总改为读取已验证翻译身份中的 native/custom term_review。

adapter 和字典实现文件 SHA 也进入翻译 checkpoint 签名；这些文件更改会使旧模型结果失效，属于保守恢复条件，可能增加重新翻译耗时。GUI 保存仍保留未展示的采样字段。当前最新 42 分段、23 HTTP、适配器和缓存检查通过；mixed 已再次完成，而错名、漏义、人称与剪映 11.4 实机证据仍未关闭。该记录写作时停止条件尚未满足；2026-10-12 两种模式均完成并验证七阶段恢复，按用户最新可用条件停止。
