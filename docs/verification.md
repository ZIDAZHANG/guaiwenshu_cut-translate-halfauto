# 验证范围与已知问题

## 整理前的真实素材证据（2026-10-12）

35 秒真实视频的 mixed、speech 两种模式各完成 15 条原 Sakura 翻译，234 个原字符没有遗漏，生成 ASS/SRT、review.csv 和导入包。恢复时各跳过七个 DONE 阶段，字幕和原模型请求 SHA 未变。各有 13 条复核、3 处 native 词条目标未遵循。

572.636 秒实际中间产物的双模式结构复核各 127 段、3641 原字符，无遗漏或越界；这不是长片完整中文准确性的证明。实际视频、字幕和原始日志未公开发布。

## 本次源码分类验证（2026-10-22）

运行入口：`python scripts/run_tests.py`。测试使用合成视频、fixture 与本地测试 HTTP 服务，不代表实际外部模型或完整桌面操作验收。具体本轮结果在 publication.md 记录；原始本地测试输出被忽略，不作为用户任务上传。

## 未关闭的边界

- 听写可能混淆歌曲名、人名及近音词，如 アルダン / ある男；翻译仍可能错人称、漏义、误处理未完句。
- native 词条可能未被模型遵循；严格字面检查也可能对同义写法报警。
- 语言残留检查不能证明中文语义准确，必须结合原音、画面和 review.csv 校对。
- GUI 启动曾实际验证；完整 GUI 交互及剪映 11.4 导入、重导入、导出没有完整实机验收。
- Qwen 强制对齐、RapidOCR 和其他翻译模型的隔离诊断未成为默认后备引擎。

本轮源码整理不宣称修复上述准确性问题，也不新增字幕长度或时长限制。
